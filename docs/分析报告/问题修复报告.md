# 问题修复报告

## 概述

本次修复涉及两个模块共 **8 个问题**，修改了 `dept_bed.c` 和 `his_main.c` 两个文件。

---

## 一、医生账号/密码问题（6 个）

### 问题 1：账号无唯一性检查

**修复**：`addDoctor()` 和 `modifyDoctor()` 中新增遍历 `doctor_list` 检查账号是否已存在。

- 新增时重复 → 报错并返回
- 修改时重复（排除自身） → 恢复旧账号并报错

### 问题 2：账号/密码可为空

**修复**：`inputDoctorInfo()` 中对姓名、账号增加非空校验循环；`addDoctor()` 中密码也做非空校验。

### 问题 3：修改医生强制重输密码

**修复**：密码在 `modifyDoctor()` 中单独处理，**直接回车则不更改**，保留旧密码。

### 问题 4：fgets 缓冲区溢出导致输入跳过（核心 Bug）

**触发条件**：输入字段 >= 49 字符时，`fgets` 未读换行符，残留数据使后续输入跳过。

**表现**：

```
请输入登录账号: 请输入登录密码: _（光标等密码）
```

**修复**：所有 `fgets` 后检查是否读到 `\n`，未读到则 `ClearInputBuffer()` 清空残留。

涉及函数：`inputDoctorInfo()`、`addDoctor()`、`modifyDoctor()`、`inputDeptInfo()`

### 问题 5：密码迁移逻辑缺陷

**修复前**：`loadDoctorData()` 中用 `isprint` 判断密码是否为明文，但 nibble-swap 后部分字符仍可打印（如 `'3'`→`'3'`、`'R'`→`'%'`），导致重启后反复混淆↔还原。

**修复**：

1. 移除 `loadDoctorData()` 中有缺陷的自动迁移
2. 迁移逻辑移至 `doctorLogin()`：先做混淆比对，失败后尝试明文兼容比对，匹配则自动迁移

### 问题 6：fgets 未检查返回值

**修复**：每个 `fgets` 增加 NULL 返回检查，遇到 EOF/错误时清空缓冲区并重试。

---

## 二、输入缓冲区问题（`\r` 残留）

### 问题 7：科室中文保存乱码

**根因**：`loadDeptData()` 没有去除 Windows 换行符 `\r`。

Windows 文件用 `\r\n` 换行。`fgets` 读入后 `strcspn` 只去掉了 `\n`，`\r` 残留在名字末尾。再次保存时 `\r` 被写回文件，造成中文数据污染。

患者使用 `LoadDataFromFile()`（有 `\r` 去除逻辑），所以患者正常。

### 问题 8：医生/床位加载同样缺 `\r` 去除

**修复**：`loadDeptData()`、`loadDoctorData()`、`loadBedData()` 统一新增 `\r` 去除逻辑：

```c
size_t _len = strlen(line);
if (_len > 0 && line[_len - 1] == '\r') line[_len - 1] = '\0';
```

### 问题 9：`modifyDept()` 使用旧式 `fgets`

**修复**：改用已修复的 `inputDeptInfo()`，消除独立的 `fgets` 溢出风险。
