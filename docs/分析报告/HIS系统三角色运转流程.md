## 五、核心业务数据流汇总

### 5.1 挂号流程中的多表联动

```
normalRegistration()
  │
  ├── 涉及表格: patient, doctor, record
  │
  ├── patient 变化:
  │     balance     -= pay (3.00)
  │     doctor_id    = "D260511001"
  │     dept_id      = "K260511001"
  │     register_status = 1 (待就诊)
  │     register_time = 系统时间
  │     record_count += 1
  │
  ├── doctor 变化:
  │     current_register += 1 (1/20)
  │
  └── record 新增:
        type = 1 (挂号)
        cost = 3.00
        detail = "普通挂号 - 费用: 3.00"
```

### 5.2 发药流程中的多表联动

```
issuePrescription()
  │
  ├── 涉及表格: drug, patient, record
  │
  ├── drug 变化:
  │     stock -= quantity (500→498)
  │
  ├── patient 变化:
  │     balance -= patient_pay (197.00→189.50)
  │     record_count += 1 (2→3)
  │
  └── record 新增:
        type = 5 (处方)
        cost = 25.00
        detail = "门诊发药: 阿莫西林胶囊 x2, 医保报销17.50元"
```

### 5.3 预约流程中的多表联动

```
appointmentRegistration()
  │
  ├── 涉及表格: patient, schedule, appointment
  │
  ├── patient 变化:
  │     balance -= pay (100.00→94.00)
  │
  ├── schedule 变化:
  │     current_patients += 1 (0→1)
```
