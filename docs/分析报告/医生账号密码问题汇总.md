# 医生账号/密码及输入问题汇总

## 问题 1：账号没有唯一性检查

**文件**：`dept_bed.c`，`addDoctor()`

创建医生时，`inputDoctorInfo` 读取账号后 **没有校验账号是否已存在**，可创建多个同账号的医生。

**修复前**：

```c
// ❌ 没有检查 account 是否已在 doctor_list 中存在
```

**修复后**（`addDoctor()` 中新增遍历检查）：

```c
ListNode* p = doctor_list->head;
while (p) {
    Doctor* existing = (Doctor*)p->data;
    if (strcmp(existing->account, d.account) == 0) {
        printf("[错误] 登录账号 '%s' 已被使用！\n", d.account);
        return;
    }
    p = p->next;
}
```

`modifyDoctor()` 同样增加了唯一性检查（排除自身），重复则恢复旧账号。

## 问题 2：账号/密码可以为空

**文件**：`dept_bed.c`，`inputDoctorInfo()` / `addDoctor()`

**修复前**：直接回车（空账号/空密码）会被保存。

**修复后**：`inputDoctorInfo()` 中对姓名、账号增加非空校验循环；密码移至 `addDoctor()` 单独处理，同样非空校验：

```c
while (1) {
    printf("请输入登录密码: ");
    if (!fgets(d.password, MAX_PWD_LEN, stdin)) { ClearInputBuffer(); continue; }
    nl = strchr(d.password, '\n');
    if (nl) *nl = '\0';
    else ClearInputBuffer();
    if (strlen(d.password) == 0) { printf("[错误] 密码不能为空！\n"); continue; }
    break;
}
```

## 问题 3：修改医生时强制重新输入密码

**文件**：`dept_bed.c`，`modifyDoctor()`

**修复前**：`inputDoctorInfo()` 强制重输所有字段（含密码）。

**修复后**：密码在 `modifyDoctor()` 中单独处理，**直接回车则不更改**：

```c
printf("请输入登录密码（直接回车则不更改）: ");
if (fgets(pwd_buf, MAX_PWD_LEN, stdin)) {
    nl = strchr(pwd_buf, '\n');
    if (nl) *nl = '\0';
    else ClearInputBuffer();
    if (strlen(pwd_buf) > 0) {
        HIS_STRNCPY(d->password, pwd_buf, MAX_PWD_LEN);
        passwordObfuscate(d->password);
    } // else 空输入，保留旧密码
}
```

## 问题 4：fgets 缓冲区溢出导致输入跳过（核心 Bug）

**文件**：`dept_bed.c`，`inputDoctorInfo()` / `addDoctor()` / `inputDeptInfo()` / `modifyDoctor()`

**触发条件**：输入的字段 **>= 缓冲区大小 - 1 字符**时，`fgets` 未读换行符，残留数据导致后续输入跳过。

**修复前**：

```c
fgets(d->name, MAX_NAME_LEN, stdin);
d->name[strcspn(d->name, "\n")] = 0;  // 没检测是否真的读到了 \n
```

**修复后**（所有 `fgets` 调用处统一修复）：

```c
char* nl;
while (1) {
    printf("请输入医生姓名: ");
    if (!fgets(d->name, MAX_NAME_LEN, stdin)) { ClearInputBuffer(); continue; }
    nl = strchr(d->name, '\n');
    if (nl) *nl = '\0';       // 正常读到换行符
    else ClearInputBuffer();   // 输入超长，清空缓冲区残留
    if (!ValidateNoPipe(d->name)) { printf("[错误] ...\n"); continue; }
    if (strlen(d->name) == 0) { printf("[错误] 姓名不能为空！\n"); continue; }
    break;
}
```

每次 `fgets` 后检查是否读到 `\n`：

- 读到 → 正常截断
- 没读到 → 输入超长，`ClearInputBuffer()` 清空残留，防止级联跳过

## 问题 5：密码迁移逻辑缺陷

**文件**：`dept_bed.c`，`loadDoctorData()` / `his_main.c`，`doctorLogin()`

**修复前**：`loadDoctorData()` 中用 `isprint` 判断密码是否为明文，但 nibble-swap 后部分字符仍可打印（如 `'3'`→`'3'`、`'R'`→`'%'`），导致重启后反复混淆↔还原，登录时断时续。

**修复后**：

1. **移除** `loadDoctorData()` 中的自动迁移逻辑
2. **迁移移至登录时**：`doctorLogin()` 先做混淆比对，失败后做明文兼容比对：

```c
// 兼容旧数据：若密码仍为明文存储，尝试明文比对并迁移
char check[MAX_PWD_LEN];
HIS_STRNCPY(check, d->password, MAX_PWD_LEN);
passwordObfuscate(check);  // nibble-swap(d->password)
if (strcmp(check, password) == 0) {
    // d->password 是明文 → 替换为混淆版本
    HIS_STRNCPY(d->password, password, MAX_PWD_LEN);
    saveDoctorData();
    // 登录成功
}
```

## 问题 6：fgets 未检查返回值

**文件**：`dept_bed.c`，`inputDoctorInfo()` / `inputDeptInfo()`

**修复前**：

```c
fgets(d->name, MAX_NAME_LEN, stdin);  // ⚠️ 未检查返回值
```

**修复后**：每个 `fgets` 增加 NULL 返回检查，遇到 EOF/错误时清空缓冲区并重试：

```c
if (!fgets(d->name, MAX_NAME_LEN, stdin)) { ClearInputBuffer(); continue; }
```
