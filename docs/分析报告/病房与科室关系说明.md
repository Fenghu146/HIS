## 科室与病房的关联

**文件**：`his.h:92-99`

```c
typedef struct {
    char id[MAX_ID_LEN];          // 床位ID
    RoomType room_type;           // 病房类型（ROOM_NORMAL / ROOM_SEMI / ROOM_VIP）
    char dept_id[MAX_ID_LEN];     // 所属科室ID ← 关联键
    BedStatus status;             // 状态（空闲/占用）
    char patient_id[MAX_ID_LEN];  // 占用患者ID
    char admit_time[MAX_TIME_LEN];// 入院时间
} Bed;
```

每个床位通过 `dept_id` 指向一个科室（`Department.id`），实现多对一关系：

```
科室 (Department: id="K001", name="外科")
  └─ 床位列表
       ├─ B001, room_type=ROOM_NORMAL, dept_id="K001"
       ├─ B002, room_type=ROOM_NORMAL, dept_id="K001"
       ├─ B003, room_type=ROOM_SEMI,   dept_id="K001"
       └─ B004, room_type=ROOM_VIP,    dept_id="K001"

科室 (Department: id="K002", name="内科")
  └─ 床位列表（类似结构，可配置不同类型的病房）
```
