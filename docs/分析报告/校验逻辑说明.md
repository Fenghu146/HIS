# 校验逻辑说明

## 1. 手机号校验 — `ValidatePhone`

**文件**：`his_tool.c:79-88`

| 规则  | 说明             |
| --- | -------------- |
| 长度  | 必须 11 位        |
| 首位  | 必须是 `1`        |
| 内容  | 全部由数字 `0-9` 组成 |

**注意**：未对号段（如 13x、18x 等）做进一步过滤。

---

## 2. 身份证号校验 — `ValidateIDCard`

**文件**：`his_tool.c:91-111`

### 第一层 — 基本格式

- 长度必须为 18 位
- 前 17 位必须全是数字
- 末位可以是数字、大写 `X` 或小写 `x`

### 第二层 — 加权校验（GB 11643-1999）

- 前 17 位分别乘以固定权重：`[7, 9, 10, 5, 8, 4, 2, 1, 6, 3, 7, 9, 10, 5, 8, 4, 2]`
- 求和后对 11 取模，得到 0~10 的索引
- 查校验码表 `"10X98765432"` 得到期望末位字符
- 实际末位（小写转大写后）与期望值比较

---

## 3. 患者访问密码

### 设置逻辑（创建/修改患者时）

- 直接回车则不设置密码
- 输入长度必须恰好 **6 位**
- 每一位必须是数字 `0-9`，否则跳过
- 密码以整数存储在 `Patient.pin` 字段
- **限制**：前导零会丢失（如 `001234` 变为 `1234`）；`pin=0` 视为"未设置密码"

### 验证逻辑 — `verifyPatientPin`

- 若 `pin == 0`，跳过验证
- 用户有 **3 次**尝试机会
- 3 次均错误则操作取消
