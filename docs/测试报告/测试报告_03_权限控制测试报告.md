## 一、权限架构概述

系统基于**角色-菜单**模型实现权限控制，共定义三种角色：

```c
typedef enum {
 ROLE_ADMIN = 0, // 管理员
 ROLE_DOCTOR = 1, // 医生
 ROLE_PATIENT = 2 // 患者
} UserRole;
```

权限控制实现方式：

- **菜单级控制**: 主菜单根据角色展示不同选项，通过登录入口（1=管理员、2=医生、3=患者）区分
- **数据级控制**: 医生端查询患者时过滤仅显示属于该医生的挂号患者
- **无页面级路由拦截**: 控制台应用，菜单即权限
